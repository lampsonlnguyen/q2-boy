Use Clang and LLD and a Q2 sysroot with glibc 2.28 and ALSA headers, and
NaN2008 shared libraries from Q2-Pod 1.8.8. The archive contains no firmware.
The layout of the sysroot is the one described in the q2-groovebox README.
Headers from Debian buster provide compatibility with the firmware loader;
copy gnu/stubs-o32_hard.h to gnu/stubs-o32_hard_2008.h in the MIPS include
directory. Compile the core and frontend with the same ABI.

    tar xf gpsp-5819380.tar.gz
    cd gpsp
    patch -p1 < ../gpsp-q2.patch
    Q2_CC="clang --target=mipsel-linux-gnu --sysroot=$SYSROOT -isystem $SYSROOT/usr/include/mipsel-linux-gnu -mabi=32 -mfp64 -mnan=2008 -mabs=2008"
    make -j4 platform=mips32 STATIC_LINKING=1 TARGET=gpsp.a CC="$Q2_CC" CXX="$Q2_CC" FRONTEND_SUPPORTS_RGB565=1
    cd ..
    SYSROOT="$SYSROOT" GPSP="$PWD/gpsp" sh build.sh q2-boy

For Gambatte, extract Debian's MIPS little-endian libstdc++-10-dev header
package separately. Set CXX_HEADERS to the extraction root and use the Q2
firmware's libstdc++.so.6 in $SYSROOT/lib. Build the shared core next to the
frontend executable.

    tar xf gambatte-77f2567.tar.gz
    CXX_HEADERS=/path/to/extracted/headers GAMBATTE="$PWD/gambatte" \
      sh build-gambatte.sh gambatte_libretro.so

The minimal homebrew test program is in smoke.s. It is independent of any
commercial ROM. The application has a local test invocation:
    q2-boy --smoke /path/to/test.gba /path/to/existing/test-directory
It creates ROMs and Saves subdirectories beneath that directory.
Run python3 make-gb-fixtures.py /path/to/fixtures to generate original GB and
GBC test ROMs. To test switching between cores, append those two ROM paths
after the test directory in the smoke command.
